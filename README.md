# Entrenamos
PWA (React + TypeScript + Vite) · rutina de 4 días con sobrecarga progresiva · Supabase + GitHub Pages.

1. Ejecuta `supabase/schema.sql` en el SQL Editor de Supabase.
2. Pon `SUPABASE_URL` y `SUPABASE_ANON_KEY` en `src/supabaseConfig.ts`.
3. Login: usuario `adrian` + el dígito X (contraseña real `00000X`).
4. Settings > Pages > Source: **GitHub Actions**.

Lógica: `src/program.ts` (rutina, RIR, series, progresión).
